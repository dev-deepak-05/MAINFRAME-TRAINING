# Inter-Branch Transfer Reconciliation

## Overview
A COBOL-based banking application designed to process and reconcile fund transfers between different bank branches.

## Features
- Inter-branch transaction processing
- Account validation
- Debit and credit operations
- Transaction verification
- Error handling and reconciliation
- Transaction status reporting

## Technologies
- COBOL
- JCL
- IBM Mainframe

## Objective
To ensure accurate and reliable fund transfers between bank branches while maintaining transaction consistency and integrity.
